## 摘要
语言引导的医学图像分割（LMIS）通过整合临床文本信息，展现出改善解剖结构和病变勾画的巨大潜力。现有方法通常依赖文本与视觉特征之间的隐式交互或辅助性的粗粒度监督来实现跨模态对齐。然而，这些方法缺乏明确且细粒度的约束以保证语义一致性，导致语言与分割输出之间不匹配。针对这一问题，我们提出文本即光照Retinex网络（TIRNet），一个新颖的受Retinex启发的框架，将文本嵌入视为用于特征调制的语义光照，从而提升LMIS中的语义一致性。TIRNet在每个解码器阶段集成了两个关键模块：（1）受Retinex启发的文本调制块（RTMB），利用正向和负向光照图增强文本相关的前景特征并抑制背景干扰；（2）一致性细节补偿块（CDCB），通过以光照可靠性为条件的一致性门控机制选择性地恢复高频细节。此外，我们提出多尺度光照监督损失（MSIS-Loss），包括区域锚定的对比损失（RGC-Loss）和背景抑制损失（BS-Loss），前者强制跨模态相似性集中在文本相关的前景区域并抑制于背景区域，后者为负向光照图提供像素级监督，共同确保每个解码器阶段精确的跨模态对齐。在MosMedData+和QaTa-COV19数据集上的大量实验表明，TIRNet在LMIS中达到了最先进的性能。代码开源在：https://github.com/anaanaa/TIRNet。

## Abstract
Language-guided Medical Image Segmentation (LMIS) has shown great potential to improve the delineation of anatomical structures and lesions by integrating clinical textual information. Existing methods generally rely on either implicit interaction between textual and visual features or auxiliary coarse-grained supervision for cross-modal alignment. However, these methods lack explicit and fine-grained constraints to ensure semantic consistency, causing a mismatch between language and the segmentation outputs. To address this issue, we propose Text-as-Illumination Retinex Network (TIRNet), a novel Retinex-inspired framework that treats text embeddings as semantic illumination for feature modulation, thereby improving semantic consistency in LMIS. TIRNet introduces two key blocks integrated at each decoder stage: (1) the Retinex-inspired Text Modulation Block (RTMB), which employs positive and negative illumination maps to enhance text-relevant foreground features and suppress background interference; and (2) the Consistent Detail Compensation Block (CDCB), which selectively recovers high-frequency details via a consistency-gated mechanism conditioned on illumination reliability. Furthermore, we propose a Multi-Scale Illumination Supervision Loss (MSIS-Loss), comprising a Region-Grounded Contrastive Loss (RGC-Loss) that enforces cross-modal similarity to be concentrated in text-relevant foreground regions and suppressed in background regions, and a Background Suppression Loss (BS-Loss) that provides pixel-level supervision for negative illumination maps, jointly ensuring a precise cross-modal alignment at each decoder stage. Extensive experiments on the MosMedData+ and QaTa-COV19 datasets demonstrate that TIRNet achieves state-of-the-art performance in LMIS. The code is available at: https://github.com/anaanaa/TIRNet.

## 2. 方法论：核心思想与关键技术细节

整体框架 **TIRNet** 采用 U 型编码器‑解码器架构，并在每个解码器阶段整合两个核心模块和一个多尺度损失函数。

### 2.1 跨模态特征提取

- **视觉编码器**：CNN 提取多尺度特征 \(\{F_{\text{enc}}^s\}_{s=1}^4\)。  
- **文本编码器**：冻结的 CLIP 模型提取 token 级特征，经一维卷积和均值池化得到全局语义嵌入 \(e \in \mathbb{R}^D\)。

### 2.2 Retinex 启发的文本调制块（RTMB）

**核心思想**：将解码器特征 \(F_{\text{dec}}\) 视为反射率 \(R\)，将文本嵌入 \(e\) 视为光照 \(L\)，通过生成正、负光照图来调制特征。

- **相似度计算**：将 \(e\) 线性投影到视觉空间得 \(t = W_p e\)；对每个空间位置计算余弦相似度，得到语义相关性图 \(A\)（形状 \(1\times H\times W\)）。  
- **正光照图 \(L^+\)**：对 \(A\) 做 3×3 平均池化和 sigmoid，得到平滑的前景激活 \(L^+ \in [0,1]\)。  
- **负光照图 \(L^-\)**：\(L^- = \sigma(-\beta A)\)，通过可学习的锐度参数 \(\beta>0\) 控制过渡，对文本无关的背景赋予高响应。  
- **Retinex 调制**：
  \[
  F'_{\text{dec}} = F_{\text{dec}} \odot (1 + \rho L^+) \odot (1 - \kappa L^-) + \gamma F_{\text{dec}}
  \]
  其中 \(\rho,\kappa,\gamma\) 分别为可学习的前景增强因子、背景抑制因子、残差保留因子。

### 2.3 一致性细节补偿块（CDCB）

**目标**：在光照调制后恢复因下采样丢失的高频边界细节，且仅恢复与文本语义一致的细节。

- **基表示** \(B\)：由 \(F'_{\text{dec}}\) 经 conv‑GELU‑conv 序列得到。  
- **编码器高频残差**：\(D_{\text{raw}} = F_{\text{enc}} - \text{AP}(F_{\text{enc}})\)（AP 为平均池化）。  
- **语义一致性门（SC‑Gate）**：
  \[
  W_{\text{cons}} = \sigma\!\left(\frac{\delta}{C}\sum_{c=1}^C \bar{q}_c \odot \bar{k}_c\right)
  \]
  其中 \(\bar{q}, \bar{k}\) 分别由 \(B\) 和 \(D_{\text{raw}}\) 经 \(1\times1\) 卷积与 GroupNorm 得到。乘性门控仅保留与解码器语义一致的细节 \(D = W_{\text{cons}} \odot D_{\text{raw}}\)。  
- **融合光照门（FI‑Gate）**：通过拼接 \([B; D; L^+]\) 经卷积和 GELU 产生门控信号 \(G\)，最终输出 \(F_{\text{out}} = B + G \odot D\)。该门控以正光照图 \(L^+\) 作为可靠信号，防止背景细节注入前景。

### 2.4 多尺度光照监督损失（MSIS‑Loss）

在每个解码器阶段 \(s\) 对光照图 \(A^{(s)}, L^{-(s)}\) 施加监督，由两部分组成：

- **区域锚定对比损失（RGC‑Loss）**  
  将真值下采样至对应尺度，划分前景区域 \(\Omega_+\) 和背景区域 \(\Omega_-\)；计算指数相似度 \(P = \exp(A)\)，分别求区域平均激活 \(\mu_+,\mu_-\)，损失为
  \[
  \mathcal{L}_{\text{rgc}}^{(s)} = -\log\frac{\mu_+^{(s)}}{\mu_+^{(s)} + \mu_-^{(s)}}
  \]
  迫使前景与背景的跨模态相似度拉开差距。  
- **背景抑制损失（BS‑Loss）**  
  \(\mathcal{L}_{\text{bs}}^{(s)} = \text{BCE}(L^{-(s)}, 1 - G^{(s)})\)，显式监督负光照图正确捕捉非目标区域。  
- 总损失：
  \[
  \mathcal{L}_{\text{total}} = \mathcal{L}_{\text{seg}} + \lambda_{\text{rgc}} \mathcal{L}_{\text{rgc}} + \lambda_{\text{bs}} \mathcal{L}_{\text{bs}}
  \]
  其中 \(\mathcal{L}_{\text{seg}}\) 为 Dice + BCE，\(\lambda_{\text{rgc}}=1.0\)，\(\lambda_{\text{bs}}=0.5\)。

## 7. 优点

- **创新性范式**：首次将 Retinex 物理模型迁移至跨模态分割，将文本编码为“光照”以驱动特征调制，思想新颖且直观。
