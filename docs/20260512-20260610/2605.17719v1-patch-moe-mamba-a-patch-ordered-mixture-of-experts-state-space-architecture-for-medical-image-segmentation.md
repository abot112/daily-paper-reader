## 摘要
基于CNN和Transformer的架构在医学图像分割中取得了强大的性能，但CNN在建模长距离依赖方面存在局限性，而Transformer通常面临平方级计算和内存复杂度。状态空间模型，尤其是基于Mamba的网络，提供了一种具有线性序列复杂度的有效替代方案。然而，现有的Mamba分割模型仍面临两个局限：逐像素的方向扫描可能破坏局部二维空间结构，而基于简单求和的扫描方向融合无法很好地适应多样化的对象大小、形状和边界。为了解决这些问题，我们提出了Patch-MoE Mamba，一种用于医学图像分割的块序混合专家状态空间架构。它引入了一种分层的块序扫描机制，在保留局部空间邻域的同时捕获多尺度上下文，以及一个基于MoE的方向融合模块，该模块使用四个方向专家、一个可学习的拼接专家和残差方向聚合来自适应地组合多个Mamba扫描器的输出。在五个公开的息肉分割基准和ISIC 2017/2018皮肤病变分割数据集上的实验证明了Patch-MoE Mamba的有效性和通用性。

## Abstract
CNN- and Transformer-based architectures have achieved strong performance in medical image segmentation, but CNNs are limited in modeling long-range dependencies, while Transformers often suffer from quadratic computational and memory complexity. State space models, especially Mamba-based networks, offer an efficient alternative with linear sequence complexity. However, existing Mamba segmentation models still face two limitations: pixel-wise directional scanning can disrupt local 2D spatial structure, and simple summation-based fusion of scan directions cannot adapt well to diverse object sizes, shapes, and boundaries. To address these issues, we propose \textit{Patch-MoE Mamba}, a patch-ordered mixture-of-experts state space architecture for medical image segmentation. It introduces a hierarchical patch-ordered scanning mechanism that preserves local spatial neighborhoods while capturing multi-scale context, and an MoE-based directional fusion module that adaptively combines multiple Mamba scanner outputs using four directional experts, a learnable concatenation expert, and residual directional aggregation. Experiments on five public polyp segmentation benchmarks and the ISIC 2017/2018 skin lesion segmentation datasets demonstrate the effectiveness and generality of Patch-MoE Mamba.

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
论文提出了 **Patch-MoE Mamba** 架构，核心由两大创新组件构成：

- **核心思想**：采用“块序（Patch-Ordered）”扫描替换像素级光栅扫描，并结合混合专家（MoE）机制实现自适应的方向特征融合。

- **关键技术一：分层块序扫描机制**
  - **块序扫描**：将特征图分割为不重叠的局部块（Patch），在每个块内部按光栅顺序访问所有像素，同一个块的像素在生成的1D序列中是连续的。这既保留了局部空间邻域，又能跨块捕获长距离依赖。
  - **分层多尺度**：在不同网络层级使用不同的块大小。浅层使用小块（如4×4）以保留精细边界细节，深层使用大块（如8×8）以捕获粗粒度语义结构。同时，4个扫描方向（正向、反向、宽高正向、宽高反向）可独立配置不同的块大小，实现多尺度与各向异性的联合建模。

- **关键技术二：基于MoE的方向融合模块**
  - **专家构建**：
    1. 将4个方向 Mamba 扫描器的输出经 Group Normalization 规范化后，作为4个方向专家 `E1` 到 `E4`。
    2. 引入第5个“拼接专家 `Econcat`”：将四者沿通道拼接，经过 1×1 卷积、批归一化与 ReLU 激活，以建模跨方向间的交互信息。
  - **空间感知门控网络**：
    1. **局部上下文**：对各方向原始输出求和后，通过 3×3 深度可分离卷积得到 `Flocal`。
    2. **全局上下文**：对求和结果进行全局平均池化后广播回原尺寸，得到 `Fglobal`。
    3. 引入可学习标量 α ∈ (0,1) 将两者融合：`Fl = α·Flocal + (1-α)·Fglobal`。
    4. 将 `Fl` 输入一个由两层 1×1 卷积构成的路由器，生成对应5个专家的空间级路由权重，经 Softmax 归一化。
  - **残差稳定聚合**：最终融合结果由专家加权和加上原始方向输出的残差连接构成：`Zl = Σ(权重 * 专家) + Σ(原始方向输出)`。这保证了即使门控网络训练初期不理想，基础的方向信号也不会丢失。

- **整体架构流程**：采用 U-Net 风格设计。将 VM-UNetV2 中的基础 VSS 块替换为上述的 Patch-MoE VSS 块，并引入 U-Net v2 的语义与细节注入（SDI）模块进行多尺度特征增强。
